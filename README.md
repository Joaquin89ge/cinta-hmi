# cinta-hmi

HMI de una cinta transportadora simulada. Trabajo práctico de Sistemas Operativos en Tiempo Real (UNLaM): una ESP32 con FreeRTOS y una pantalla en Linux con GuiLite.

Qué se construye y qué decisiones están firmes está en [docs/contexto.md](docs/contexto.md). Cómo compilar, flashear y abrir la ventana está en [docs/entorno.md](docs/entorno.md).
